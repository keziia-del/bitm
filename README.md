# Learn GitHub Together 🚀

A tiny website (HTML + CSS + JavaScript) used to practice Git and GitHub.

## Your task
Add yourself to the **Class Contributors** section.

1. **Fork** this repository (button at the top right)
2. **Clone** your fork:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```
3. **Create a branch:**
   ```bash
   git checkout -b add-my-name
   ```
4. Open `script.js` and add a line to the `contributors` list
5. Open `index.html` in your browser to check it works
6. **Commit and push:**
   ```bash
   git add script.js
   git commit -m "Add <your name> to contributors"
   git push origin add-my-name
   ```
7. On GitHub, open a **Pull Request** 🎉

## Files
| File | What it does |
|------|--------------|
| `index.html` | Page structure |
| `style.css` | Colors and layout |
| `script.js` | Contributor cards, counter, dark mode |

## Live site
Enable **Settings → Pages → Deploy from branch → main** to publish it with GitHub Pages.
